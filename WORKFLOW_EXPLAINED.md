## 🎯 Полный Цикл: Как Изменения Доходят До Сайта

### Шаг 1️⃣: Меняете Код Локально

**Где:** На вашем компьютере, в VS Code

```bash
# 1. Откройте папку проекта в VS Code
# Файл → Открыть папку → выберите chefai.kz/

# 2. Найдите файл который хотите изменить
# Например: src/App.tsx

# 3. Измените код
# Найдите: bg-indigo-600
# Замените на: bg-red-600

# 4. Сохраните (Ctrl+S или Cmd+S)
```

**Что происходит:** Файл на вашем компьютере изменился. **Пока только локально!**

---

### Шаг 2️⃣: Проверяете Локально

**Где:** На вашем компьютере, в браузере

```bash
# В терминале VS Code:
npm run dev

# Откройте в браузере: http://localhost:3000
```

**Что происходит:** 
- Vite запускает локальный сервер
- Вы видите изменения **только вы** на своем компьютере
- Изменения автоматически обновляются в браузере (Hot Reload)
- **Никто в интернете это НЕ видит!**

---

### Шаг 3️⃣: Сохраняете в Git (Локально)

**Где:** На вашем компьютере, в Git

```bash
# В терминале:
git add .                           # Добавить все изменения
git commit -m "Изменил цвет кнопки" # Сохранить с описанием
```

**Что происходит:**
- Git создает "снимок" ваших изменений
- Это как сохранение в игре - можете вернуться назад
- **Всё ещё только на вашем компьютере!**
- **Никто в интернете это НЕ видит!**

---

### Шаг 4️⃣: Отправляете на GitHub

**Где:** Отправка в облако GitHub

```bash
# В терминале:
git push
```

**Что происходит:**
- Код отправляется на github.com
- Теперь код в облаке, доступен из любого компьютера
- **Другие разработчики могут увидеть изменения в GitHub**
- **Но сайт пока НЕ обновился!**

---

### Шаг 5️⃣: Vercel Автоматически Деплоит

**Где:** Vercel сервер

**Что происходит (АВТОМАТИЧЕСКИ!):**
1. Vercel видит что код на GitHub изменился
2. Автоматически скачивает новый код
3. Запускает `npm install` и `npm run build`
4. Публикует собранный сайт
5. Через 1-2 минуты сайт обновляется!

**URL обновляется:**
```
https://chefai-kz-git-copilot-refactor-8d42ce...
```

**Теперь ВСЕ в интернете видят изменения!** 🎉

**Местоположение:**

- Исходный код (src/)

**URL:** https://github.com/lolgin/chefai.kz

- История всех изменений

### 3. Vercel (Хостинг)

**URL:** https://chefai-kz.vercel.app/

**Что здесь:**
- Только собранные файлы (dist/)
- Нет исходного кода
- Готовый сайт для пользователей

## 💡 Частые Вопросы

### Q: Я изменил код, но сайт не обновился!

**A:** Проверьте что сделали ВСЕ шаги:

```bash
# 1. Сохранили файл в VS Code? (Ctrl+S)
# 2. Добавили в Git?
git add .

# 3. Сделали commit?
git commit -m "Описание"

# 4. Отправили на GitHub?
git push

# 5. Подождали 1-2 минуты для Vercel?
```

---

### Q: Как увидеть изменения БЕЗ публикации в интернет?

**A:** Используйте локальный dev-сервер:

```bash
npm run dev
# Откройте http://localhost:3000
# Меняйте код - изменения видны мгновенно!
# Только вы видите, никто в интернете не видит
```

---

### Q: Где посмотреть что именно изменилось?

**A:** Используйте Git:

```bash
# Что изменилось (не сохранено)?
git status

# Что именно изменилось в файлах?
git diff

# История сохранений:
git log --oneline
```

**В VS Code:** 
- Иконка "Source Control" (третья слева)
- Показывает все изменения
- Можно посмотреть построчно

---

### Q: Как вернуть всё назад?

**A:** 3 способа:

```bash
# 1. Отменить НЕсохраненные изменения в одном файле:
git checkout -- src/App.tsx

# 2. Отменить ВСЕ несохраненные изменения:
git reset --hard

# 3. Вернуться к предыдущему commit:
git log --oneline      # найдите нужный commit
git reset --hard abc123  # вернитесь к нему
```

---

### Q: Сколько времени занимает публикация?

**A:** Таймлайн:

```
Сохранили в VS Code (Ctrl+S)     → 0 секунд
git add + commit                   → 1 секунда
git push                           → 5-10 секунд
Vercel начал сборку                → 10 секунд
Vercel собрал проект               → 30-60 секунд
Сайт обновился                     → ГОТОВО!

Итого: ~1-2 минуты от git push до обновления сайта
```

## 📝 Практическое Упражнение

Попробуйте пройти весь цикл:

### 1. Измените что-то простое:

**Файл:** `src/constants.tsx`

**Найдите (строка ~15):**
```tsx
{
  id: 'frost',
  name: 'Clean Frost',
  bg: '#f8f9ff',
  accent: '#4f46e5',
```

**Измените на:**
```tsx
{
  id: 'frost',
  name: 'Clean Frost',
  bg: '#fff0f0',        // Розовый фон
  accent: '#ef4444',    // Красный акцент
```

### 2. Проверьте локально:

```bash
npm run dev
# Откройте http://localhost:3000
# Цвета изменились? ✅
```

### 3. Сохраните в Git:

```bash
git add src/constants.tsx
git commit -m "Изменил тему Frost на розовую"
```

### 4. Отправьте на GitHub:

```bash
git push
```

### 5. Проверьте на Vercel:

```
Подождите 1-2 минуты
Обновите страницу: https://chefai-kz-git-copilot-refactor...
Цвета изменились на сайте? ✅
```

**Поздравляю!** Вы прошли полный цикл разработки! 🎉
