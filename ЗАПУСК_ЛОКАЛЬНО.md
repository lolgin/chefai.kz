# 🚀 Как запустить приложение локально

## Быстрый старт (5 минут)

### 1. Установите Node.js (если еще не установлен)
Скачайте Node.js версии 18 или выше с официального сайта:
- **Windows/Mac**: https://nodejs.org/
- **Linux**: `sudo apt install nodejs npm` или `brew install node`

Проверьте установку:
```bash
node --version  # должно показать v18.0.0 или выше
npm --version   # должно показать версию npm
```

### 2. Клонируйте репозиторий (если еще не сделали)
```bash
git clone https://github.com/lolgin/chefai.kz.git
cd chefai.kz
```

### 3. Установите зависимости
```bash
npm install
```
Это займет 1-2 минуты. Установятся все необходимые библиотеки (React, Vite, TypeScript, и т.д.)

### 4. (Опционально) Создайте файл .env.local для Gemini API
Если хотите использовать AI-генерацию метаданных, создайте файл `.env.local` в корне проекта:
```bash
# .env.local
GEMINI_API_KEY=ваш_ключ_api_здесь
```

**Где взять ключ?** https://ai.google.dev/

**Важно:** Приложение работает и без API ключа! Просто AI-метаданные не будут генерироваться.

### 5. Запустите dev-сервер
```bash
npm run dev
```

Вы увидите:
```
  VITE v6.4.1  ready in 182 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: http://192.168.x.x:3000/
```

### 6. Откройте в браузере
Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

**Готово!** 🎉 Приложение запущено локально!

## 🔄 Как видеть изменения в реальном времени

### Hot Module Replacement (HMR)
Vite автоматически обновляет страницу при изменении кода!

1. **Запустите dev-сервер**: `npm run dev`
2. **Откройте код** в редакторе (VS Code, WebStorm, и т.д.)
3. **Измените любой файл** в `src/`
4. **Сохраните** (Ctrl+S / Cmd+S)
5. **Браузер обновится автоматически!** ⚡

### Пример изменений в реальном времени

**Хотите изменить цвет?** Откройте `src/constants.tsx`:
```tsx
// Найдите тему 'frost' и измените цвета
{
  id: 'frost',
  name: 'Clean Frost',
  bg: '#f8f9ff',      // ← измените это на '#ff0000' (красный)
  accent: '#4f46e5',  // ← или это на '#00ff00' (зеленый)
  // ...
}
```
Сохраните - и цвета изменятся мгновенно!

**Хотите изменить текст кнопки?** Откройте `src/App.tsx`:
```tsx
// Найдите строку с BOOT_SYSTEM (около строки 250)
<button>BOOT_SYSTEM</button>  
// Измените на
<button>ЗАПУСТИТЬ</button>
```
Сохраните - и текст кнопки обновится!

## 🎨 Как тестировать изменения

### 1. Изменение компонентов
Все компоненты находятся в `src/components/`:

```bash
src/components/
├── Player/
│   ├── PlayerControls.tsx    # ← Кнопки play/pause
│   ├── VolumeControl.tsx      # ← Слайдер громкости
│   └── TrackInfo.tsx          # ← Информация о треке
├── Modules/
│   ├── DiscoveryModule.tsx    # ← Поиск станций
│   ├── ThemesModule.tsx       # ← Выбор тем
│   └── ...
└── ...
```

**Пример**: Измените размер кнопки Play:
```tsx
// src/components/Player/PlayerControls.tsx
<button
  onClick={onTogglePlay}
  className="w-16 h-16 ..."  // ← измените w-16 h-16 на w-20 h-20
>
```

### 2. Изменение логики
Вся бизнес-логика в `src/hooks/`:

```bash
src/hooks/
├── useAudioPlayer.ts       # ← Логика плеера
├── useStreamDiscovery.ts   # ← Логика поиска
└── useSystemLogs.ts        # ← Логика логов
```

### 3. Изменение стилей
Проект использует **Tailwind CSS**. Классы можно менять прямо в компонентах:
- `bg-indigo-600` - фон
- `text-white` - цвет текста
- `p-4` - отступы
- `rounded-xl` - скругление углов

**Полная документация Tailwind**: https://tailwindcss.com/docs

## 🐛 Решение проблем

### Ошибка: "Cannot find module"
```bash
npm install  # Переустановить зависимости
```

### Ошибка: "Port 3000 is already in use"
```bash
# Остановите другой процесс на порту 3000
# Или измените порт в vite.config.ts:
server: {
  port: 3001,  // ← измените порт
}
```

### Приложение не обновляется после изменений
1. Остановите сервер (Ctrl+C)
2. Очистите кэш: `rm -rf node_modules/.vite`
3. Запустите снова: `npm run dev`

### Аудио не воспроизводится
1. Откройте консоль браузера (F12)
2. Проверьте CORS ошибки
3. Убедитесь, что нажали кнопку "BOOT_SYSTEM" для инициализации аудио
